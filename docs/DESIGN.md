# 行迹 · 设计系统

> 暖纸为底，林绿为骨，赤陶为心跳；衬线讲故事，无衬线讲事实。

行迹是一个「私人旅行日记」，不是工具型 App。视觉上要同时成立两件事：**照片要好看**，**文字要好读**。所以整站以暖纸为画布，让照片成为唯一的高饱和元素。

## 色彩

| Token | 值 | 用途 |
|---|---|---|
| `--paper` | `#F7F3EA` | 页面底色，永远不要用纯白替代 |
| `--paper-deep` | `#EFE8D9` | 次级底、标签底、地图未点亮区域 |
| `--surface` | `#FFFFFF` | 卡片、输入框 |
| `--ink` | `#1E211F` | 标题与主文本（不用纯黑） |
| `--body` | `#414743` | 正文 |
| `--muted` | `#77807A` | 元信息 |
| `--line` | `#E5DFD1` | 分隔线 |
| `--forest` | `#2F5D50` | 唯一行动色：主按钮、激活态、地图点亮 |
| `--forest-soft` | `#E4EDE8` | 选中底、空状态图标底 |
| `--clay` | `#DE6A3E` | 情感强调：最近一次旅行、重要提示 |
| `--clay-soft` | `#FBEDE6` | 提示底 |
| `--ochre` | `#C08A3E` | 评分、暖色点缀 |

规则：

- 每屏最多两处林绿、一处赤陶，其余让给照片和纸色
- 大地色只做装饰，不做按钮
- 功能图标一律 `ink` 或 `muted`，不用彩色图标

## 字体

| 角色 | 字体栈 | 用法 |
|---|---|---|
| 叙事 | `--serif`：Noto Serif SC / Songti SC / STSong | 页面标题、卡片标题、空状态标题 |
| 事实 | `--sans`：Inter / PingFang SC / HarmonyOS Sans SC | 正文、按钮、表单、元信息 |
| 数字 | `--sans` + `font-variant-numeric: tabular-nums` | 统计、日期、金额 |

层级（移动端）：

| Token | 字号 / 字重 | 用途 |
|---|---|---|
| display | 30px / 600 serif | 页面主标题 |
| section | 18px / 600 serif | 区块标题 |
| body | 15px / 400 | 正文 |
| small | 13px / 400 | 辅助说明 |
| caption | 11px / 400 | 元信息、标签 |
| eyebrow | 11px / 600，字距 2.4px，大写 | 小标 |

衬线只用在 18px 以上；中文衬线在小字号会糊。

## 间距与形状

- 4px 基准：`4 / 8 / 12 / 16 / 20 / 24 / 32`
- 页面左右边距：20px；卡片内边距：16–18px
- 圆角：`10 / 14 / 18 / 24 / full`
- 阴影只有两级：卡片 `--shadow-card`，浮层 `--shadow-float`
- 同一屏最多两种圆角半径

## 组件

- **TabBar**：白底 + 上边线 + 毛玻璃；高 56px + `env(safe-area-inset-bottom)`；激活为林绿
- **卡片**：白底、18px 圆角、`--shadow-card`
- **主按钮**：林绿实心、全圆角、48px 高、60% 屏幕宽以上
- **空状态**：56px 圆形图标底 + 一句标题 + 一句说明 + 一个行动按钮，文案要有温度
- **轻提示**：深色半透明胶囊，位于 TabBar 上方 20px
- **地图**：未点亮 `paper-deep`，去过 `forest`，多次更深的苔藓色；最近一次旅行用赤陶圆点

## 移动端规范

- 所有可点区域 ≥ 44×44px
- 用 `env(safe-area-inset-*)` 处理刘海与底部横条
- 布局用 `100dvh`，不用 `100vh`
- 优先底部抽屉，不用居中弹窗
- 不用 hover 承载信息；按压用 `:active` 的轻微缩放
- 尊重 `prefers-reduced-motion`

## 文案

- 用具体名词，不用「数据」「内容」这类抽象词
- 空状态给方向，不给压力：「还没有旅行」比「暂无数据」好
- 避免营销腔（「极致」「宝藏」「秒变」）

## Do / Don't

**Do**

- 让照片承担视觉重量，标题克制
- 用「纸 vs 白」的微差分层，阴影只做辅助
- 数字等宽，列表对齐不跳动

**Don't**

- 不要用纯白做页面背景
- 不要给标题加 700 以上字重
- 不要彩色渐变按钮、玻璃拟态卡片、霓虹描边
- 不要超过三级阴影
