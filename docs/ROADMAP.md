# 路线图

版本号遵循语义化版本；每个版本都会打 tag 并更新 [CHANGELOG](../CHANGELOG.md)。

## v0.1.0 · 骨架（已完成）

- 应用外壳、四个 Tab、设计 token
- PWA 安装与离线
- CI + GitHub Pages 部署
- 文档、贡献指南、许可证

## v0.2.0 · 照片与标注（已完成）

- 旅行 CRUD（新建 / 编辑 / 删除）
- 照片导入：多选、EXIF 时间与 GPS、压缩、缩略图、进度条
- 照片标注：灵感 / 趣事的正文与标签、删除照片
- 按天时间线（按拍摄时间自动分组）、相册瀑布流
- 全屏查看：左右滑 / 键盘切换
- 暂缓：Demo 示例数据（留给 v0.3.0）

## v0.3.0 · 地图点亮（已完成）

- 中国省级 GeoJSON 简化与 canvas 绘制
- 足迹点亮、分级填色、点选省份看旅行
- 最近一次旅行赤陶标记
- 顶部统计：省份 / 城市 / 照片
- 地图纳入离线缓存

## v0.4.0 · 备份与发布（已完成）

- 导出 zip（JSON + 照片）与导入恢复
- 合并 / 覆盖两种恢复模式
- 备份提醒
- 示例数据
- 首次正式 Release（v0.4.0）

## v0.4.1 · Android APK（已完成）

- Capacitor 套壳与品牌图标
- GitHub Actions 自动出包（tag → Release APK）
- 正式签名流程（release.keystore + GitHub Secrets）

## v0.4.2 – v0.4.4 · Android 打磨（已完成）

- 修复 APK 白屏（相对路径 base、关闭 WebView 内的 Service Worker）
- 接管系统返回键：子页面回上一级、Tab 页回足迹、优先关闭照片查看器与弹层
- 应用内更新检查（GitHub Releases）与更新弹层

## v0.5.0 · 世界地图（可选）

- 国家边界 GeoJSON 与切换
- 大洲概览

## v1.0.0 · 可用版

- 稳定数据格式与迁移
- 年度回顾长图
- 足迹连线

## 明确不做

- 账号系统、社交 feed、评论
- 行程规划、记账
- AI 自动写游记（可作为独立实验，不进入主线）
